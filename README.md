# Bavesh — Developer Portfolio

A responsive dark-themed developer portfolio built with React, Vite, CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite.

## Before publishing

- Replace `Bavesh` if you want a different display name.
- Update the About section to match your real experience.
- Replace sample project cards and their GitHub links with your actual projects.
- Update the email, GitHub, and LinkedIn links in `src/App.jsx`.
- Do not claim a project is complete unless you have actually built it.

## Build check

```bash
npm run build
```

## Deploy

Push this repository to GitHub, then import it at https://vercel.com/new. Vercel should detect Vite automatically. Use `npm run build` as the build command and `dist` as the output directory if asked.
